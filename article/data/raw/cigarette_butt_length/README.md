# Cigarette-butt length data: pending source recovery

The thesis contains only the final length figure. Individual measurements and
the original plotting code were not located, so approximate group means must
not be used to reconstruct observations.

If the measurements are recovered, store them as
`cigarette_butt_length_raw.csv` with this structure:

```text
sample_id,treatment,length_cm
```

Each row should represent one measured cigarette butt. Record the source,
replicate count, and any exclusion criteria in this file.
