# Comprimento das bitucas — dados pendentes

Este diretório está reservado para os dados individuais usados na comparação do
comprimento das bitucas sem tabaco (BST) e com tabaco remanescente (BCT).

## Situação

- A monografia apresenta apenas o gráfico final (`tamanho_bitucas.png`).
- Os dados individuais e o código original não foram localizados.
- O texto informa médias aproximadas de 2,5 cm para BST e 3,5 cm para BCT e
  diferença estatisticamente significativa (`p < 0,05`). Esses valores não devem
  ser usados para reconstruir dados individuais.

## Ação manual necessária

Quando os dados forem recuperados, colocar aqui uma tabela em formato longo,
preferencialmente `cigarette_butt_length_raw.csv`, com as colunas:

```text
sample_id,treatment,length_cm
```

Cada linha deve representar uma bituca medida. Registrar também, neste arquivo,
a origem das medidas, o número de réplicas e qualquer critério de exclusão.
